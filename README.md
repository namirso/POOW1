# Trabalho de Programação Orientada a Objetos WEB I

## Desenvolvido por mim!

### Re-VIU? - Site para registrar sua análise em determinada obra da cultura pop.

- Com foco em experiência do usuário, neste software é possível criar uma review para determinada obra que deseja, assim como ver reviews dos demais usuários da aplicação.

### Principais pontos

- Criação de análise;
- Edição e Exclusão de análise criada;
- Visualização de análise própria e públicas;
- Edição breve de perfil;

  ### Possíveis pontos a serem adicionados para melhoria da aplicação

  - Pedido de obras para análise, visto que as obras disponíveis todas constam em banco de dados próprio;
  - Edição mais elaborada de perfil;
  - Criação mais específica de análise;
  - Mecanismo de busca;
  - Método de reação a demais análises;
